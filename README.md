# 1C Universal Dev

Codex skill для разработки и анализа решений на платформе 1С:Предприятие 8.

## Содержимое

- SKILL.md — маршрутизация задач и общие правила.
- references/ — инструкции по коду, ревью, БСП, запросам, формам, архитектуре, расширениям, правам, интеграциям, тестированию и сопровождению.
- agents/openai.yaml — имя, описание и настройки вызова skill.
- scripts/validate-skill.ps1 — проверка целостности пакета и публичной папки без изменения файлов.
- scripts/check-bsl.ps1 — необязательный эвристический поиск нескольких BSL-паттернов; вывод требует ручного ревью и не заменяет проверку платформой или АПК.
- XML-каталоги-шаблоны для внешних отчётов и обработок.

Локальные пользовательские настройки не входят в репозиторий. Созданный при использовании файл user-context/user-preferences.yaml игнорируется Git.

## Проверка пакета

Из корня каталога skill запустите `pwsh -NoProfile -File ./scripts/validate-skill.ps1`.
Для папки, подготовленной к публичной загрузке, добавьте `-Public`; проверка обнаружит включённый профиль пользователя, отсутствие его правила в `.gitignore` или каталог `.git`.

BSL-сканер запускается отдельно и вручную: `pwsh -NoProfile -File ./scripts/check-bsl.ps1 -Path <файл-или-каталог>`. Он выдаёт только кандидаты на ручную проверку.

Режимы `ревью` и `БСП` можно указать явно в запросе к skill; остальные режимы выбираются по общим правилам из `SKILL.md`.

## Установка

Установите папку этого репозитория в каталог skills вашей версии Codex либо добавьте её в проект в .agents/skills/1c-universal-dev/. Актуальные варианты установки описаны в [документации Codex Skills](https://developers.openai.com/codex/skills).
